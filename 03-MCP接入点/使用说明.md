# 03 MCP 接入点（mcp-endpoint-server）

小智（xiaozhi-esp32-server）的 MCP 注册中心，基于 FastAPI + WebSocket，
跑在 Docker 容器 `xiaozhi` 里，监听 **:8004**。它自己不含业务逻辑，
只负责把「工具端」和「小智端」的消息互相转发。

上游项目：`xinnan-tech/mcp-endpoint-server`（`README.md` / `README_dev.md` 是原版的）。

## 结构

```
main.py                       入口
src/                          服务实现
mcp-endpoint-server.cfg       配置（host/port/token/日志）
requirements.txt              依赖（x86）
requirements-riscv64.txt      RISC-V 依赖
Dockerfile / docker-compose.yml
docs/schematic.png
```

## 启动

```bash
docker exec -d xiaozhi bash -lc 'cd /opt/mcp-endpoint-server-main && nohup /opt/venv-mcp-endpoint/bin/python main.py > /tmp/mcp_ep.log 2>&1'
```

要用 **`/opt/venv-mcp-endpoint/bin/python`**（装了 fastapi/uvicorn）。

启动后日志会打印两个地址，按部署方式选一个：

```
ws://<板子IP>:8004/mcp_endpoint/mcp/?token=xxxx
```

这个地址就是 `04-MCP管道与Modbus工具/` 里 `.env` 的 `MCP_ENDPOINT`，
小智语音端也用它来注册。

## 验证

```bash
ss -lntp | grep 8004
docker exec xiaozhi tail -20 /tmp/mcp_ep.log
```

日志里出现 `Application startup complete.` 和 `Uvicorn running on http://0.0.0.0:8004` 即成功。

## 注意

- 配置里的 `token` 是接入凭证，**不要提交到公开仓库**。本仓库没有包含运行时的 `.env`。
- `logs/`、`data/` 是运行时产物，已排除。
- 容器用 host 网络，所以 `8004` 直接暴露在板子 IP 上。
