# 05 标定与调试脚本

现场调阈值、测性能、抓原始数据用的工具。大部分不需要改动主程序就能跑。

## 最常用：现场标定记录器

`points_log.py` —— 挂在板子上常驻，只把"雷达看到点"的那些秒写进日志，
用来搞清楚「站着的时候到底多少个点」「站立时 z 最高点多少」。
调 `MMWAVE_PERSON_MIN` / `MMWAVE_MIN_RANGE` / 跌倒判据全靠它。

```bash
cd /home/testk1/mmwave
nohup python3 points_log.py > /dev/null 2>&1 &
tail -f logs/points.log        # 然后去雷达前面站 20~30 秒
```

输出长这样（同时给过滤前和过滤后两组数）：

```
[17:23:41] 原始  62点 x -0.42~+0.38 y +1.62~+1.94 z -0.55~+1.21 | 过滤后  62点 y +1.62~+1.94 z -0.55~+1.21 | 人=有 状态=normal
```


## 一个必须知道的坑

雷达一直 10 帧/秒在发，但**没人时帧里 0 个点**，这种帧头体只有 32 个 hex
（要求 40 个），解析函数会返回 `None`，整帧被丢弃。
所以"没有点云"有两种完全不同的原因：

- **A**：雷达在发，只是范围内没人 → 包数在涨，带点的包为 0
- **B**：串口根本没数据 → 包数不动

`/status` 里的 `radar_pkt_rate`（总包数）和 `radar_hit_rate`（有点的包数）
就是用来区分这两种情况的。B 要查串口权限（`sudo usermod -aG dialout $USER`）。
